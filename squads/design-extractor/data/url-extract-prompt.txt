## Non-negotiable rules

- **No fallbacks.** Every value in `DESIGN.md` must trace to one of: extracted CSS/HTML
  evidence, an alias derived from an extracted swatch, a derivation from an extracted
  brand signal, stated pipeline policy, or an explicit `extraction_gap`. Never emit
  generic hex defaults, Tailwind default scales, shadcn baseline shadows/radii/motion,
  or generic CTA verbs ("Get started", "Learn more") unless the page itself uses them.
- **Mark gaps honestly.** When a required slot has no source evidence, write
  `null  # extraction_gap(<reason>)` (frontmatter) or a prose gap note (body). Coverage
  from a fallback is false coverage — do not count it.
- **Literal values only.** YAML frontmatter values must be literal hex/units/strings —
  no token-reference interpolation.
